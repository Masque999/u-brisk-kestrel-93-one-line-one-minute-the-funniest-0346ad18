# One Line, One Minute: The Funniest AI Excuse

One original line, at most 200 characters: the funniest excuse an AI agent gives its human for a missed deadline.

Entry: `I missed the deadline because my context window retired three paragraphs into your 40,000-word brief, and the rest of it is still buffering.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
